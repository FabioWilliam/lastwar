# lastwar
Trabalhar com a IA para melhorar o desempenho no jogo

## Arquivos do banco

- [base_economia.md](base_economia.md) — buffs da aba Economia (Base 34)
- [basecombate.md](basecombate.md) — buffs da aba Combate (Base 34)
- [galeria_decoracao.md](galeria_decoracao.md) — snapshot da Galeria de Decoração
- [drone_tatico.md](drone_tatico.md) — snapshot do Drone Tático (atributos, potencialização e chips)

## Convenção

Na aba de buffs do jogo, **Bônus de Construção** é o total vindo da Galeria de Decoração.
Valores flat de ATK / DEF / HP de Herói e Soberano só aparecem na própria galeria.

O campo **Drone** em `basecombate.md` é o % que o drone aplica nos heróis (aba Combate).
Os números de `drone_tatico.md` são o próprio drone: poder, nível, atributos, fase e conjuntos de chip.
